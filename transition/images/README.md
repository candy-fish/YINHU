# 映相（独立草稿）

星空仅分布在屏幕上方三分之一，边缘柔和淡出。星点密度适度提高，使用 100–500 颗自适应星点，并在后方叠加很淡的冰蓝、粉紫星云光雾；下方照片与时间轴区域保持原有背景。

星云前景使用固定在门左缘的独立裁切层，视差和透视仅在层内运动，仍可向门的右侧和上方浮出。极光以五层 Blender 光幕配合两道远处短光褶，分别进行连续缓波、纵深摆动、向上细丝流动和沿光幕传播的明暗变化，保留原有五色参考配色。独立星空层仅在屏幕上方三分之一生成约 100–500 颗疏密错落的星点，并带有很淡的星云光雾，少量亮星带柔光，各自缓慢闪烁；约每秒十次更新，与页面共用时钟，减少动态效果时静止。

鹿和鱼使用独立场景位置追赶视图，自身速度最多 280 场景单位/秒，步频最多约 1.4 Hz。快速拖动允许它们落后；仍可见时继续追上，完整离开画面后，松开进度条并等视图稳定约 0.32 秒，会在当前视图中以 2.6 秒全息效果重现。数字光条环绕旋转，菲涅尔轮廓、字符碎片与扫描光带由下向上逐步补全模型，然后光条淡出。重现期间保持站姿；再次移动后继续限速追赶。系统减少动态效果时直接回到当前位置，不播放重现动画。

跳跃使用同侧前后腿配合；背部通过 Blender 形态键收展，头颈随落地回弹，身体俯仰与四肢使用同一动作周期。中低速奔跑完整采用成组相位，不叠加残留的四拍步行。

最新长跳参考 `20261024-1944-03.9629584.mp4`：延长腾空到约 56% 周期、适当降低步频、加大向前伸腿幅度。同样的时间轴速度下，单次跳跃覆盖更长距离，保持原来的视觉大小与跳高；松手后继续完成落地。

动作进一步舒展：腾空时前腿前探、后腿后展，减轻收腿和弓背幅度，颈部向前送、蹄尖放松。同侧腿仍共享起落节奏，保留关节可达、落地稳定和原来的站姿。

当前视觉使用 `#C5D951` 光路、门框与全息鹿鱼，`#39B6D8` 信息框线，`#C8EDEF` 信息文字。门内心脏／灵魂星云使用用户参考图片，背景、气体和近景星点分层，通过 CSS 透视与鼠标视差向门外展开。顶部极光使用 Blender 制作的五层独立曲面，保留冰蓝、薄荷、浅粉、灰紫与浅桃配色；下沿为连续缓弧，各层亮边错开，细丝向上渐隐。形变只做轻微漂移，不产生急折和折返。源文件与构建方法见 `../../art/images-aurora/README.md`。`aurora-3d.js` 以最多约 15 帧/秒渲染，和鹿鱼共用 Three.js bundle；`aurora.js` 提供原生 WebGL 降级。极光、星云与鹿鱼共用页面时钟；系统减少动态效果时停用循环与视差。

窗口带有照片原色的柔光，悬停与键盘聚焦时增强光晕及画面亮度，不添加实体画框。仅展示当前浏览器保存的自建窗口，没有记录时保留空白时间轴，不预置示例内容。自建窗口使用各自封面的色彩生成柔光。

鹿和鱼优先使用 Blender 导出的连续蒙皮 GLB，`companion-art.js` 中的内联 SVG 关节造型作为降级方案。`companions.js` 根据限速追赶时自身的实际位移触发动作，拖动进度条、悬停、键盘和触摸使用相同逻辑。鹿保持原来的视觉大小，极慢速时四拍行走，中低速持续移动即可平滑进入奔跑，步频、步幅随速度变化。跳跃参考用户视频，强化蹬伸、上抛、收腿、下降伸腿和落地缓冲，延长腾空段；画布增加顶部留白，保留像素比例与落脚位置，避免鹿角裁切。速度过滤、迟滞及同相位混合避免切换抖动；单次跳转会触发限速追赶。松手时完成正在进行的跳跃，再逐腿落稳，之后间歇张望、低头吃草。小鱼随奔跑程度摆尾、摆鳍更快，身体轻摆、穿梭更活跃，减速后逐渐恢复静止环游；保持原大小和前后遮挡。启用系统“减少动态效果”时保留位置跟随，停止循环动画。参考出处及参数说明见 [动作参考](assets/motion-reference.md)。

本页的窗口和封面只保存在当前浏览器、当前站点来源的 IndexedDB（`blackdoor-images`）中。它们不会上传、不会跨设备同步；更换浏览器、切换域名或端口、清除网站数据，都可能让原有窗口不可见或删除其内容。请保留照片原件。

每个封面支持 JPEG、PNG、WebP、GIF 或 AVIF，最大 12 MiB。数据库保存失败时会显示错误，不会回退为刷新后丢失的临时保存。

`image-store.js` 导出 Promise API：`listWindows()`、`saveWindow(record)`、`deleteWindow(id)`。创建时不传 `id`；编辑时传已有的 `id`，`createdAt` 会保留。`imageURL(record)` 返回临时 Blob URL，使用结束后由调用方执行 `URL.revokeObjectURL(url)`。

窗口使用 `frame: { width, height, y }` 保存用户绘制的大小和垂直位置，单位为场景坐标，保留一位小数。`normalizeFrame(frame)` 与 `FRAME_LIMITS` 供绘制界面共用：宽度为 80–640，高度为 64–440，顶部至少为 40，底部不超过 520。旧版按小、中、大保存的窗口会在读取时转换为相应尺寸，原有数据库和封面继续保留。

照片不带实体画框；悬停或键盘聚焦时，右侧粉蓝全息面板展示标题、时间、材质和场景尺寸（px）。投影通过透明底色、静态粉蓝渐变边线及轻微浮动文字呈现，系统减少动态效果时停止动画。`material` 是自由填写的介绍文字，支持换行，最多 600 字。时间可输入 `2022.1.2-2022.3.4`，保存为 ISO 格式的 `date` 与可选 `dateEnd`，按开始日期排序。旧记录无需迁移，缺少的字段按空白读取。创建界面左侧封面预览保持绘制比例，右侧没有占位文案，向上箭头提交保存。
