# 映相极光源文件

2026-10-26 网页增强：保留五层原始 GLB 曲面，额外复用其中两层生成更短、更远的光褶，改变比例、位置、深度及独立流动相位；无需覆盖 Blender 工程。顶点着色器只改变纵向和纵深，维持横向连续、不折返。细丝向上输运，光幕沿横向产生缓波及局部光簇变化。繁星改由独立 `night-stars.js` 画布绘制，保持点光源清楚，不与极光一起模糊。

`映相-立体极光.blend` 是可独立打开的 Blender 场景。`build_aurora.py` 通过本地 Blender MCP 生成五层独立曲面，共 18,335 个顶点，包含 UV、发光透明材质和 `Flow A` / `Flow B` 两组循环形变。

曲面沿横向和纵深连续展开，冰蓝和薄荷两层主光带使用不对称宽缓弧线，粉色与其他淡光帘退到远处，避免整齐平行排列。宽缓褶皱在端部平滑收束，避免折返和密集波纹。形变幅度限制在轻微漂移范围。冰蓝 `#BBD7E5`、薄荷 `#BBDDC5`、浅粉 `#EBCEE5`、灰紫 `#77718F`、浅桃 `#ECC5B9` 来自用户的配色参考，形态参考用户提供的极光图片，几何为原创程序建模。

网页资产导出至 `transition/images/assets/aurora-curtains.glb`，保留曲面、UV、形变、配色和远近强度元数据。网页在 `aurora-3d.js` 中使用无缝循环噪声贴图的 R/G/B 通道分别控制细丝、光雾团簇和细丝高度，避免直线亮边与整齐梳齿。向上的光丝在光雾中逐渐消散，随页面时钟更新。透明画布使用预乘 Alpha 和正常透明混合，防止叠加后浅色变成灰白。注意 glTF UV 的 V 轴相对于 Blender 翻转，网页需反转 V。

修改网页材质后运行 `node scripts/build-images-companions.mjs`。重建 Blender 场景前应使用新的 `SCENE` 名称，脚本会拒绝覆盖已存在的场景，避免影响用户的其他 Blender 工作。
